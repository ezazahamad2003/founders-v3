# Production Hotfix - January 5, 2026

## Critical Bugs Fixed

### 1. Document Content Truncation (HIGH SEVERITY)
**Issue:** Legal documents were being truncated to only 6,000 characters (~1,000 words), causing incomplete contract analysis.

**Root Cause:** `MAX_CHARS_PER_FILE = 6000` in `document_text.py` was too small for typical contracts.

**Fix:** Increased to `MAX_CHARS_PER_FILE = 50000` (~8,000 words)

**Impact:** 
- ✅ Full Terms of Use documents now extracted completely
- ✅ Contracts up to ~30 pages fully processed
- ✅ No impact on performance (still within GPT-4 context limits)

**Files Changed:**
- `backend/app/services/document_text.py` (line 20)

---

### 2. File Context Not Persisting in Conversation (HIGH SEVERITY)
**Issue:** When users uploaded a document and asked follow-up questions, the document context was lost after the first message. Only the chat text history was maintained.

**Root Cause:** `chat.py` only processed files from the current message request (`payload.file_ids`), not files from previous messages in the conversation.

**Fix:** 
- Fetch message history BEFORE file validation
- Collect file_ids from ALL messages in history
- Validate and include ALL conversation files in context

**Impact:**
- ✅ Documents remain in context for entire conversation
- ✅ Follow-up questions now have access to uploaded files
- ✅ Contract review follow-ups work correctly

**Files Changed:**
- `backend/app/routers/chat.py` (lines 58-100)
